Omarchy Backup

Privacy policy

Effective October 27, 2026. Maintained by GitHub user texacony for personal use.

Data and purpose

The desktop backup setup reads selected files and settings on the owner's computer to create encrypted recovery backups. Restic encrypts backup contents and filenames before transfer. Rclone transfers the encrypted repository to a dedicated folder in the owner's Google Drive using Google's Drive API.

Access and storage

The setup requests the Google drive.file scope, permitting access to files created by or explicitly authorized for this app. OAuth credentials and the backup password are stored locally with restricted file permissions. Google receives encrypted backup data and necessary service metadata, and processes it under its own policies. Local backups may be unencrypted.

Sharing and retention

The maintainer does not sell Google user data or use it for advertising or AI model training. No backup contents or credentials are published on this site or GitHub. Cloud backups remain until the owner removes them or enables a retention policy. The owner can revoke the app's access through Google Account settings and delete the dedicated backup folder in Google Drive.

This website

This site has no analytics scripts, forms, or app-managed cookies. GitHub Pages may process visitor connection information according to GitHub's privacy statement. Do not post passwords, credentials, or private backup contents in public issues.

Questions: contact the maintainer through GitHub.
