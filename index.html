Omarchy Backup

A personal backup setup maintained by GitHub user texacony. It uses Restic and Rclone to encrypt selected computer files locally and store recovery copies in the owner's Google Drive.

This is a private, personal-use desktop setup, not a public backup service. This website hosts information only; it does not sign visitors in or process backups.

The Google connection requests the limited drive.file permission. Backup operations are configured to use a dedicated folder. Existing unrelated Google Drive files are not part of the backup destination.
